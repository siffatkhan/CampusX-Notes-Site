Day 2

Deep Learning vs. Machine Learning

Deep Learning (DL) is a subset of Machine Learning (ML) built around artificial neural networks — models loosely inspired by how neurons in the brain connect and pass signals to one another. The word "deep" refers to the number of layers stacked between the input and the output: a network with several hidden layers between input and output is considered "deep," as opposed to a "shallow" model with just one or two.

The practical distinction that matters most day-to-day is who does the feature engineering. In classical ML, a human decides which input features matter — for example, hand-picking "size," "location," and "number of rooms" before feeding them to a regression model. In deep learning, the network is given comparatively raw data (pixels, audio waveforms, raw text) and learns the useful intermediate representations — edges, shapes, phonemes, word relationships — on its own, layer by layer, without a human manually designing them.

Key takeaway

Deep learning is not a replacement for machine learning — it is machine learning done with neural networks deep enough to learn their own features. That extra depth is what lets it handle unstructured data (images, audio, text) that classical ML struggles to hand-engineer features for.

Day 3

Types of Neural Networks

Different problems shape data differently — a photo, a sentence, a stock-price sequence, and a fraud signal are not the same kind of object — and different neural network architectures exist because each one is built around assumptions that fit a particular shape of data well. Here are the five foundational types.

1. Multi-Layer Perceptron (MLP)

An MLP is the most basic deep learning architecture: an input layer, one or more hidden layers, and an output layer, with every neuron in one layer connected to every neuron in the next (a "fully connected" or "dense" network). It makes no special assumption about the structure of the input — it just treats it as a flat vector of numbers — which makes it general-purpose but less efficient than specialized architectures for images or sequences. It is used mostly in supervised learning tasks on tabular or already-vectorized data, such as predicting a price from a handful of numeric features or classifying a fixed-size feature vector.

2. Convolutional Neural Network (CNN)

A CNN is built around the idea of scanning small, learnable filters ("kernels") across an input to detect local patterns — edges, textures, shapes — and then combining those local detections into increasingly abstract features in deeper layers. This weight-sharing structure makes CNNs far more efficient than an MLP at processing grid-like data, because the network doesn't need a separate weight for every pixel-to-neuron connection. CNNs are used mostly in image and video processing — classification, object detection, segmentation — and are also applied to any data with a strong local/spatial structure.

3. Recurrent Neural Network (RNN)

MLPs and CNNs are feed-forward networks — information flows in one direction only, from input to output, with no memory of what came before. An RNN is different: at certain points inside the hidden layers, information is fed back into the network as it processes the next item in a sequence, effectively giving the network a form of memory of everything it has seen so far, which it uses to improve its next prediction. Because of this looping structure, RNNs are used for time series, sequential data, and ordered data in general — things like sentences (where word order matters), stock prices over time, or sensor readings collected over time.

4. Autoencoders

An autoencoder is trained to reconstruct its own input: it takes input data, squeezes it through a narrow "bottleneck" layer that forces the network to compress it into a smaller representation, and then tries to reconstruct the original input from that compressed representation as accurately as possible. In other words, the goal is to compress data without losing quality, and by doing so the network is forced to learn which features of the data are actually essential to keep. This makes autoencoders useful for dimensionality reduction, denoising, anomaly detection, and as a building block inside more advanced generative models.

5. Generative Adversarial Networks (GANs)

A GAN pits two networks against each other: a generator, which tries to produce fake data realistic enough to pass as genuine, and a discriminator, which tries to tell real data apart from the generator's fakes. As training proceeds, the generator gets better at fooling the discriminator, and the discriminator gets better at catching it — an adversarial back-and-forth that (ideally) pushes the generator toward producing highly realistic outputs. GANs are the architecture behind synthetic image generation, deepfakes, data augmentation, and other generative tasks.

Hard

5 questions on Day 2–3. Pick an answer for each, then check.

1. What is the single biggest practical difference between classical ML and deep learning, per the source notes?

Explanation: Classical ML relies on humans selecting/engineering features; deep networks learn useful intermediate representations automatically, layer by layer, which is why they scale well to raw, unstructured data.

2. Which architecture is defined by feeding information from hidden layers back into itself, giving it a form of memory across a sequence?

Explanation: MLPs and CNNs are feed-forward — info moves start to end linearly. RNNs loop info back inside the hidden layers, which is exactly what enables them to model sequential/time-series data.

3. An autoencoder's defining structural feature is:

Explanation: Autoencoders compress input data into a smaller representation without losing important quality, then reconstruct the original from that compressed form — forcing the network to learn which features matter most.

4. In a GAN, what is the role of the discriminator?

Explanation: The generator produces fakes; the discriminator's job is to catch them. Their adversarial competition is what drives the generator to improve.

5. Why is an MLP a poor structural fit for raw image data compared to a CNN?

Explanation: An MLP is fully connected and structure-agnostic, so it needs a huge number of weights and ignores spatial locality. CNNs share weights via small local filters scanned across the grid, exploiting the fact that nearby pixels are related.
