3. Multi-Layer Perceptron

Weight Notation · Why Stacking Perceptrons Creates Nonlinear Boundaries · The Complete Pipeline

Day 8

MLP Notation

Once a network has more than one perceptron arranged across multiple layers, we need a consistent way to name every single weight — a plain "\(w\)" is no longer enough because there could be hundreds of them. The standard scalar notation used for this is:

$$ w_{ij}^{[l]} $$
SymbolMeaning
\(l\)The index of the current layer the weight feeds into — e.g. \([1]\) for the first hidden layer, \([2]\) for the second hidden layer, and so on.
\(i\)The index of the neuron in the previous layer that the weight originates from.
\(j\)The index of the neuron in the current layer \([l]\) that the weight connects to.

Worked example

\(w_{23}^{[1]}\) reads as: the weight on the connection from the 2nd neuron in the previous layer (here, the input layer) to the 3rd neuron in the 1st hidden layer. Breaking the symbol apart: the superscript \([1]\) tells you "we are looking at the first hidden layer"; the first subscript \(2\) tells you "the signal is coming from neuron #2 of whatever layer feeds into this one"; the second subscript \(3\) tells you "it's landing on neuron #3 of the current layer." Every single weight in a network — no matter how large — can be uniquely named this way, which is exactly what makes it possible to write backpropagation's update rules generically for a network of any size.

Day 9

MLP Intuition

A single perceptron cannot create a nonlinear decision boundary because it is, structurally, a linear model — its output is always some linear combination of its inputs passed through one activation function, which geometrically can only ever be a straight line or flat hyperplane. The fix is not to make one perceptron smarter; it's to combine multiple perceptrons into a network — a Multi-Layer Perceptron — that as a whole is capable of representing far more complex, curved decision boundaries.

How does an MLP create a nonlinear boundary?

Each individual neuron in a hidden layer still only draws its own straight line. But an MLP takes several of these individually-linear neurons and forms linear combinations of them in the next layer — that is, it weights and sums together the outputs of several straight-line neurons, then applies another activation function on top. Combining several straight lines this way, and then bending each combination through a nonlinearity, lets the network carve out a decision region built from many straight-line segments — which, especially with more layers and more neurons, can approximate curved boundaries of essentially any shape. Each additional hidden layer effectively lets the network combine the previous layer's shapes into an even more complex shape.

Universal function approximator

This is the core reason neural networks are described as universal function approximators: given enough hidden layers, enough neurons, and enough training time, a neural network can approximate essentially any mathematical function that maps inputs to outputs — linear or not. This doesn't mean any specific small network can learn any function easily or efficiently, only that the architecture itself has no theoretical ceiling in the same way a single linear perceptron does.

The One Equation to Remember

For every single neuron in an MLP, regardless of which layer it sits in, the computation performed is always identical in form:

$$ z = \sum_i w_i x_i + b, \qquad a = f(z) $$

\(x_i\) = inputs to the neuron; \(w_i\) = learnable weights; \(b\) = learnable bias; \(z = \sum w_i x_i + b\) = the pre-activation sum; \(f(\cdot)\) = the activation function; \(a\) = the neuron's output, which becomes an input to the next layer.

Adding nodes to the output layer

For multiclass classification, the output layer is given multiple nodes — one per class — where the node producing the highest probability tells us which class the network believes the input belongs to. Similarly, when the underlying relationship in the data is highly complex, adding more and more hidden layers gives the network the extra capacity needed to shape a decision boundary complex enough to fit it — which loops back to the "universal function approximator" idea above.

Test Your Understanding

Hard

5 questions on Day 8–9. Pick an answer for each, then check.

1. In the notation \(w_{ij}^{[l]}\), what does the subscript \(i\) represent?

Explanation: \(l\) is the current layer, \(i\) is the source neuron in the previous layer, and \(j\) is the destination neuron in the current layer \([l]\).

2. What does \(w_{23}^{[1]}\) refer to?

Explanation: Superscript [1] = 1st hidden layer is the destination layer; first subscript 2 = source neuron #2 (previous layer); second subscript 3 = destination neuron #3 (current layer).

3. Why can't a single perceptron create a nonlinear decision boundary?

Explanation: A single perceptron is structurally a linear model; combining multiple perceptrons across layers is what lets the network form a nonlinear boundary.

4. In the MLP pipeline diagram, what step comes immediately after "Compute Loss"?

Explanation: The pipeline goes: prediction → compute loss → backpropagation (gradients) → update weights → repeat.

5. For any neuron in an MLP, the "one equation to remember" is z = Σwᵢxᵢ + b, a = f(z). What does 'a' represent?

Explanation: z is the pre-activation sum of weighted inputs plus bias; a = f(z) is the neuron's actual output after applying the activation function, which is passed to the next layer.
