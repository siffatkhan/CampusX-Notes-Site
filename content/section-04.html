Day 11

Tensors

A tensor is a container / data structure for numbers. A matrix is a tensor. A NumPy nd-array is a tensor. ML uses mostly 0D to 5D tensors.

Tensor Type Meaning Example Axes / Dimensions Shape Where Used Extra Explanation
0D Tensor (Scalar) Single number. No axis. 3, 7, 2 0 axes () Basic arithmetic A scalar is the smallest unit of data. No length, no row, no column.
1D Tensor (Vector) List of numbers. One axis. [1,2,3,4,5] 1 axis (length) (5) Features, tokens, embeddings A vector has magnitude or direction in math. In ML it stores simple sequences.
2D Tensor (Matrix) Table of numbers. Rows and columns. [[1,2,3],[5,6,7],[8,9,0]] 2 axes (rows, columns) (3,3) Tabular data, weights, grayscale images Most common tensor in data science. Each row is one sample or feature.
3D Tensor Stack of multiple 2D matrices. Sentence example: [[1,0,0,0],[0,1,0,0]] 3 axes (num_matrices, rows, columns) — NLP, time-series, embeddings. Think of it as "multiple tables stacked on top of each other." Example: 3 sentences → (3,2,4).
4D Tensor Stack of 3D tensors. Images: (N,H,W,C) 4 axes (batch, height, width, channels) — CNNs, image processing. Each image has height, width, and color channels. Batch adds one more axis.
5D Tensor Stack of 4D tensors. Videos: (N,F,H,W,C) 5 axes (batch, frames, height, width, channels) — Video models, action recognition. A video is a series of images (frames), so you add a frame axis.
Illustrative aid — generated for this site, not quoted from the source notes.

Quick Concept Summary

  • Higher rank = more axes
  • Shape tells how many elements are stored along each axis
  • Images add the channel dimension
  • Videos add the frame dimension
  • Batches add the batch dimension
  • Rank = number of axes. Scalar 0, vector 1, matrix 2, video batch 5.
  • Shape = elements per axis. Example: (2,3) → 2 rows, 3 columns.
  • Size = multiply shape. (2,3) → 6 items.

Quick Practical Summary

  • 1D → row of values
  • 2D → matrix or table
  • 3D → sentences, time series batches
  • 4D → image batches
  • 5D → video batches
Day 12

Virtual Environment

  • Base environment contains global libraries.
  • Virtual environment creates an isolated workspace.
  • Each project has its own versions of libraries.
  • Reduces conflicts, makes deployment stable on servers.
  • Good practice for Django, Flask, ML, and production apps.
  • Deep learning needs GPUs.
  • Use Google Colab to run notebooks with GPU or TPU.
  • Logistic Regression draws the best line that separates two classes.
Day 14

Framing the Problem

  1. Turn a business question into a prediction or classification task.
  2. Decide if labels exist. Supervised = labels present. Unsupervised = no labels.
  3. Check if an existing product or model solves the problem.
  4. Gather data from internal or external sources.
  5. Decide performance metric. Accuracy, F1, RMSE, MAE.
  6. Choose training mode. Batch learning trains on full dataset. Online learning updates model with new data continuously.
  7. Check assumptions. Data quality, distribution, size, balance, missing values.

Churn Rate

  • Number of users leaving in a time period.
  • Growth happens when new users > churned users.
  • Decline happens when churned users > new users.

Test Your Understanding

Hard

5 questions on Day 11–14. Pick an answer for each, then check.

1. You load a batch of 32 color images, each 64×64 pixels, into a single tensor for a CNN. What is the shape and rank of this tensor?

Explanation: Images are the canonical 4D tensor example: (N,H,W,C) = (batch, height, width, channels). 32 images of 64×64 with 3 color channels gives shape (32,64,64,3), a rank-4 tensor — no frame axis is added since this isn't video.

2. You now batch 10 short video clips, each with 8 frames of 64×64 RGB images. Per the notes' pattern for 5D tensors, what's the shape?

Explanation: The notes give the exact video-tensor convention: (N,F,H,W,C) — batch, frames, height, width, channels. So 10 clips × 8 frames × 64×64 × 3 channels = (10,8,64,64,3), a 5D tensor (stack of 4D tensors, one per clip).

3. Two developers on the same machine need scikit-learn 1.0 and scikit-learn 1.4 respectively for two different projects, without breaking either. What does the source notes recommend and why?

Explanation: Per Day 12, the base environment contains global libraries while a virtual environment creates an isolated workspace so each project has its own versions of libraries — precisely to avoid this kind of version conflict.

4. A subscription app had 500 users start and 300 users cancel this month. Per the Churn Rate notes, what is happening to the user base, and which "Framing the Problem" step does tracking this most directly support?

Explanation: New users (500) exceed churned users (300), which the notes define as growth. Churn rate is exactly the kind of business-facing metric that Step 5 ("Decide performance metric") of Framing the Problem asks you to define before modeling.

5. Which statement correctly distinguishes a 3D tensor from a 2D tensor, per the notes' own NLP example?

Explanation: The notes describe a 3D tensor as a "stack of multiple 2D matrices" — think of it as multiple tables stacked on top of each other. The worked example is 3 sentences → shape (3,2,4), adding a num_matrices axis on top of the (rows, columns) axes a 2D matrix has.
