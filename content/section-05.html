Day 18

Web Scraping

Web scraping is the last data-gathering technique in this arc: pulling data directly out of a website's HTML when no CSV, JSON, SQL source, or API is available for it. The source notes for this day are limited to the heading itself — the practical scraping workflow (fetching page HTML and parsing it with a library like BeautifulSoup) is covered as part of the broader Data Gathering skillset alongside CSV/TSV, JSON/SQL, and APIs above.

Test Your Understanding

Hard

5 questions on Day 15–18. Pick an answer for each, then check.

1. A 40GB CSV won't fit in memory, and a few of its rows are malformed (extra commas) causing parser crashes. Which combination of read_csv arguments addresses both problems?

Explanation: chunksize handles files too large for memory by loading and processing in chunks inside a loop; on_bad_lines="skip" skips corrupted/malformed lines instead of crashing the parser. The other pairs solve unrelated problems (column selection/naming, date parsing/value cleaning).

2. A CSV uses "-" and "NA" as placeholders for missing prices instead of leaving cells blank, so pandas loads them as ordinary strings rather than NaN. Which argument fixes this at load time?

Explanation: na_values lets you mark custom strings (like "-" or "null") as missing values so pandas converts them to NaN on load, rather than treating them as literal text. dtype forces a column's type but won't recognize custom missing markers on its own.

3. You need to pull live currency exchange rates that update every minute from a third-party service into your Python script. Per Day 17, what's the mechanism, and what Python library executes it?

Explanation: Per Day 17, APIs are a data pipeline connecting two software systems, and Python's requests library is used to make an HTTP request that hits any route/API — exactly the tool for pulling live third-party data like exchange rates.

4. Your source data lives in a relational database and you only need the results of a specific filtered query, not the whole table. Which loading method is the right fit?

Explanation: pd.read_sql_query takes a SQL query string plus a connection object, so a filtered SELECT with a WHERE clause pulls exactly the subset needed directly from the database — unlike read_json (file-based) or read_csv (flat-file based).

5. A dataset you need for a project doesn't exist as a downloadable file and the site publishing it offers no API. Which of the four Day 15–18 techniques is the appropriate last resort, and why?

Explanation: Web scraping exists precisely for the case where no CSV/JSON/SQL export and no API are available — you pull the data straight out of the rendered HTML instead. Option D is wrong because not every site exposes an API, which is exactly why scraping is needed as a fallback.
