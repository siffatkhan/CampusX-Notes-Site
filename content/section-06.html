Understanding Gathered Data — Asking Basic Questions

import pandas as pd
df = pd.read_csv("train.csv")

Once loaded, a fixed set of questions helps you get oriented in a new dataset fast:

# Question Method What it does
1 How big is the data? df.shape → tells us the size of the data
2 How does the data look like? df.head()
df.sample(5)		 → head() previews first 5 rows; sample(5) gives 5 random rows to avoid biasedness that lies somewhere in the data (much better approach)
3 What is the data type of columns? df.info() → tells us about datatypes
4 Are there any missing values? df.isnull().sum()
(df.isnull().mean()*100)		 → gives total missing values per column; the second line gives percentage — helps decide drop or fill
5 How does the data look mathematically? df.describe() → gives mathematical summary of all numerical columns: mean, std, min, max
6 Are there any duplicate values? df.duplicated().sum()
df.drop_duplicates(inplace=True)		 → gives total duplicate rows; second line removes duplicates
7 How is the correlation between columns? df.corr() → Pearson correlation for numerical columns. Positive means direct relation, negative means inverse relation

Day 20

Understanding Gathered Data — EDA (Univariate Analysis)

Univariate Analysis looks at a single variable (column) at a time. Used to find frequency, distribution, outliers, skewness.

A. Categorical Data

Check frequency of categories.

# 1. Countplot
import seaborn as sns
sns.countplot(x='Survived', data=df)

# 2. Value counts
df['Survived'].value_counts()

# 3. Bar chart
df['Survived'].value_counts().plot(kind='bar')

# 4. Pie chart (percentage)
df['Survived'].value_counts().plot(kind='pie', autopct='%.2f')
Notes: Use countplots for comparison. Pie charts are useful only when categories are few.

B. Numerical Data

Continuous values like Age, Height, Salary.

# 1. Histogram — turns continuous data into ranges (bins)
plt.hist(df['Age'], bins=5)

# 2. Displot — improved histogram with probability density
sns.displot(df['Age'])

# 3. Boxplot — 5-number summary (Min, Q1, Median, Q3, Max)
sns.boxplot(y=df['Age'])
Histogram — good for distribution shape.
Displot — shows peaks, spread, skew.
Boxplot — detects outliers (points outside 1.5 × IQR). Use for outlier removal.

Other plots: violinplot — shows distribution + density (rarely used); rugplot — shows raw data points (rarely used).

Basic Stats:
df['Age'].min()
df['Age'].max()
df['Age'].mean()
df['Age'].skew() (positive skew = tail to right, negative = tail to left)
Day 21

Understanding Gathered Data — EDA (Bivariate Analysis)

Bivariate Analysis looks at two variables at a time. EDA plots depend on the data type interaction:

  • Categorical vs Categorical → countplot, heatmap
  • Numerical vs Numerical → scatterplot, line plot
  • Categorical vs Numerical → bar plot, box plot, violin plot

Goal: check relationships, detect patterns, measure impact of one variable on another.

1. Scatter Plot (Numerical vs Numerical)

sns.scatterplot(x=total_bill, y=tip, hue=sex, style=smoker, size=size)

Use when — both variables are continuous; relationship strength matters.

Why use — shows correlation trend, detects clusters, detects outliers; hue and style show category impact.

Special case — use line plot instead when x-axis is time.

2. Bar Plot (Numerical vs Categorical)

sns.barplot(x=Pclass, y=Fare, hue=Sex)

Use when — numerical value depends on categories; comparison between groups.

Why use — shows average or aggregate value, easy comparison across categories.

Note — bars represent mean by default; not suitable for distribution shape.

3. Box Plot (Numerical vs Categorical)

sns.boxplot(x=Sex, y=Age)

Use when — distribution matters; outliers matter.

Why use — shows median and spread, detects outliers, compares distributions across groups.

Best for — age, income, price comparisons.

4. Distplot (Numerical)

sns.distplot(df['Age'])

Use when — distribution shape matters.

Why use — shows skewness, shows peaks, shows spread.

Note — histogram + density curve; use before transformation.

5. Heatmap (Categorical vs Categorical)

sns.heatmap(pd.crosstab(sex, survived))

Use when — comparing two categorical variables; pattern visibility matters.

Why use — shows intensity pattern, faster comparison than tables.

Limitation — percentages not shown directly.

# Fix — show percentages instead
titanic.groupby('sex').mean()['Survived'] * 100

6. Clustermap (Categorical vs Categorical)

sns.clustermap(pd.crosstab(SibSp, Survived))

Use when — behavior similarity matters.

Why use — groups similar rows and columns, shows hidden structure.

Best for — behavioral analysis, pattern grouping.

7. Pairplot (Multiple Numerical values)

sns.pairplot(df)

Use when — many numerical variables exist; quick overview needed.

Why use — scatter of every numeric pair, diagonal shows distribution, best bird-eye view.

Limitation — slow for large datasets.

8. Line Plot (Numerical vs Numerical)

sns.lineplot(x=date, y=sales)

Use when — x-axis represents time; trend over time matters.

Why use — shows trend, shows seasonality; better than scatter for time data.

Quick Decision Rule

  • Relationship strength → Scatter
  • Time trend → Line
  • Group comparison → Bar
  • Distribution + outliers → Box
  • Category frequency → Countplot
  • Many numerics → Pairplot
  • Category interaction → Heatmap
  • Similar behavior → Clustermap

Extra Important Points (added for better understanding)

  • Numerical data has distribution shape (normal, skewed)
  • Skewed data may need log/box-cox transformation
  • Outliers can distort mean, correlation, and model accuracy
  • Always check value imbalance in categorical columns
  • Use describe(include='all') to summarize both numeric and categorical data
  • Matplotlib is the older library for visualization, while seaborn is the modern one built on top of matplotlib
Day 22

Pandas Profiling Tool

Purpose

Automates Exploratory Data Analysis. Generates a full HTML report from a DataFrame. Saves time compared to manual EDA.

What the report shows

  • Dataset overview
  • Number of rows and columns
  • Data types
  • Missing values count and percentage
  • Duplicates
  • Descriptive statistics
  • Correlation matrix
  • Distribution of each column
  • Warnings about data quality issues

Used when

  • Quick understanding of a new dataset
  • Initial EDA before modeling
  • Checking data quality problems early
import pandas as pd
df = pd.read_csv("train.csv")

!pip install ydata_profiling
from ydata_profiling import ProfileReport
prof = ProfileReport(df)
prof.to_file(output_file="output.html")

Best Practice

Profiling saves time. Manual EDA builds intuition. Use profiling first, then do manual EDA — combine both for best results.
