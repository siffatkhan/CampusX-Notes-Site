7. Feature Engineering

Feature Transformation · Construction · Selection · Extraction

Day 23

Feature Engineering (IMP)

Feature engineering is the process of creating, modifying, and selecting input features using domain knowledge so ML models learn patterns better and give higher accuracy.

Purpose

  • Improve model performance
  • Reduce noise
  • Make patterns easier for algorithms to learn
  • Reduce overfitting and training time

Data Preprocessing vs Feature Engineering

Data Preprocessing

  • Works on raw data
  • Focuses on data quality (accuracy, completeness, consistency)
  • Makes data usable
  • Steps include cleaning, formatting, and fixing errors

Examples: handling missing values, removing duplicates, fixing inconsistent data, correcting data types.

Feature Engineering

  • Works after basic preprocessing
  • Focuses on features, not raw data
  • Shapes data for better learning
  • Strongly depends on domain knowledge

1. Feature Transformation

Modify existing features so algorithms perform better.

a. Missing Value Imputation
  • Mean, median, mode
  • KNN imputation
  • Model based imputation
b. Handling Categorical Variables
  • Label Encoding
  • One Hot Encoding
  • Target Encoding
c. Outlier Handling
  • Detection using IQR, Z score
  • Capping
  • Removal when justified
d. Feature Scaling
  • Standardization
  • Normalization
  • Min Max scaling

Used for: distance based models, gradient descent based models.

2. Feature Construction

Create new features from existing ones.

Feature splitting

Example: Date → day, month, year

Feature grouping

Example: Age → age groups

Mathematical combinations

Example: length × width = area

Goal: capture hidden patterns, add meaningful information.

3. Feature Selection

Select only important features for the model.

Why needed: reduce overfitting, improve model speed, remove irrelevant and redundant features.

Filter methods

correlation, chi square

Wrapper methods

forward, backward selection

Embedded methods

Lasso, decision trees

4. Feature Extraction

Automatically transform data into new features, usually reducing dimensions.

Key idea: original features are replaced with new ones.

Examples: PCA, LDA, t-SNE.

Real world example: instead of number of rooms and washrooms, use total area in square feet.

Used when: data has high dimensions, visualization is needed, noise reduction is required.

5 questions on Day 23. Pick an answer for each, then check.

1. A dataset has inconsistent date formats and duplicate rows that need to be fixed before anything else can happen. Which stage does this belong to, and what comes right after it in the pipeline described?

Explanation: Fixing inconsistent data and removing duplicates are explicitly listed as Data Preprocessing examples. The notes state Feature Engineering "works after basic preprocessing" — so preprocessing always comes first.

2. You split a "full_address" column into street, city, and zip code, and you also bucket a raw "age" column into "18-25", "26-40", etc. Which single Feature Engineering category covers both actions?

Explanation: Splitting a column (Date → day, month, year style) is "feature splitting" and bucketing a numeric column (Age → age groups) is "feature grouping" — both are named techniques under Feature Construction, whose goal is capturing hidden patterns and adding meaningful information.

3. A dataset has 500 columns and you use a Lasso regression's coefficient shrinkage to automatically zero out unhelpful features during model fitting. Which Feature Selection method category is this, and how does it differ from a filter method?

Explanation: The notes name Lasso and decision trees explicitly as embedded methods — selection is baked into training. Filter methods (correlation, chi square) score features independently before any model runs; wrapper methods (forward/backward selection) explicitly test different feature subsets against a model in a search loop.

4. A housing dataset has "num_rooms" and "num_washrooms" as separate columns. Following the notes' own real-world example, replacing both with a single "total_area_sqft" feature is best classified as which technique, and why not Feature Selection?

Explanation: This is the notes' own worked example for Feature Extraction, whose key idea is "original features are replaced with new ones" — distinct from Feature Selection, which only chooses a subset of existing features without creating new ones from combinations of the old ones.

5. A KNN model (a distance-based algorithm) is performing poorly because one feature ranges 0-1 and another ranges 0-100,000, so the larger-range feature dominates distance calculations. Which Feature Transformation sub-technique directly fixes this, and what category does it fall under?

Explanation: Feature Scaling (standardization, normalization, min max scaling) is listed under Feature Transformation and the notes explicitly say it's "used for: distance based models, gradient descent based models" — KNN being the canonical distance-based model affected by unscaled feature ranges.
