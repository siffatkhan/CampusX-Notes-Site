Feature Scaling (Feature Transformation)

Feature scaling is a technique used before training ML models to bring all independent features to a similar scale or range.

Why feature scaling is needed

  • Some features have large values and dominate others
  • Distance based algorithms get biased
  • Gradient descent becomes slow or unstable
  • Model accuracy drops without scaling

Required for

  • Distance based algorithms
  • Gradient descent based algorithms

Not required for

  • Tree based models

Types of Feature Scaling

1. Standardization (Default Choice)

Also called Z-Score Normalization. Transforms data so mean becomes 0 and standard deviation becomes 1.

$$ z = \frac{x - \mu}{\sigma} $$
Properties
  • No fixed range and handles negative values
  • Suitable when min and max values are unknown
When to use
  • Data follows normal distribution
  • Outliers exist but are not extreme
  • Most ML models use this one
Day 25

Feature Scaling — Normalization

2. Normalization scales data into a fixed range. Use when min and max values are known. General range: 0 to 1, or −1 to 1.

a. Min-Max Scaling (use when bounds are known — most commonly used)

$$ x' = \frac{x - x_{min}}{x_{max} - x_{min}} $$

Properties: values fall between 0 and 1; sensitive to outliers.

b. Mean Normalization

$$ x' = \frac{x - \mu}{x_{max} - x_{min}} $$

Properties: data centered around 0; rarely used in practice. Reason: standardization performs better in most cases.

c. Max Absolute Scaling

$$ x' = \frac{x}{\max(|x|)} $$

Properties: range −1 to 1; preserves zeros. When to use: sparse data (having more zero values).

d. Robust Scaling

Uses median and Interquartile Range (IQR).

$$ x' = \frac{x - \text{median}}{IQR} $$

When to use: data contains many outliers; outliers are important and cannot be removed.

Deep dive: StandardScaler and fit_transform Explained
Purpose
  • Standardize numeric features so they have mean = 0 and std = 1.
  • Makes all features comparable for ML models (Logistic Regression, SVM, etc.).
Line we are studying 
X_train_scaled = scaler.fit_transform(X_train)
Step-by-step working

1. Fit (compute mean and std) — fit calculates mean and standard deviation of each numeric column in training data, and saves internally in the scaler: scaler.mean_ → column-wise mean, scaler.scale_ → column-wise std.

# Column Age = [20, 30, 40]
mean = (20+30+40)/3 = 30
std = sqrt(((20-30)**2 + (30-30)**2 + (40-30)**2)/3) ~= 8.165

2. Transform (scale data) — for each value: X_scaled = (X - mean) / std. Using the example above: 20 → (20-30)/8.165 ≈ -1.224, 30 → 0, 40 → 1.224. Result: a new array where each column has mean=0, std=1.

3. fit_transform — shortcut that does fit + transform together on training data, and saves mean/std internally for later use on test data.

4. Transform test data

X_test_scaled = scaler.transform(X_test)

Do not fit again on test — use mean/std from train to scale test data. This prevents data leakage (ensures consistency).

Why this is important
  • Without scaling, features like Fare (0–500) would dominate smaller features like SibSp (0–8).
  • Standardization helps the model treat all features equally.
Summary
  • fit_transform → compute mean/std from train, scale train data
  • transform → scale test data using train statistics
  • Keeps train/test on the same scale, avoids data leakage

Extra — Decimal Scaling Normalization

Purpose: to move the decimal point of values until they fall within a small range, typically (-1, 1).

$$ x' = \frac{x}{10^{j}} $$

Where j is the number of digits in the largest absolute value.

Example: Data: [12, 100, 500]. Largest value = 500 → 3 digits → j = 3. x' = 12/1000 = 0.012, 100/1000 = 0.1, 500/1000 = 0.5. Normalized data → [0.012, 0.1, 0.5]

When to use: when you want a quick, simple normalization and your data has consistent scale (no huge outliers).

Discretization (Preview)

Discretization converts continuous numerical data into discrete categories or bins.

Examples: Age → 0–10, 11–20, 21–30; or Age → young, adult, old.

Why used: simplify data, improve interpretability, useful for rule based models.

Types: equal width binning, equal frequency binning. (Covered in full on Day 32 — Binning & Binarization.)

Test Your Understanding

Hard

5 questions on Day 24–25. Pick an answer for each, then check.

1. A dataset has a column that is extremely sparse (95% zeros) with a few large positive and negative values. Which scaler best preserves the sparsity structure?

Explanation: Max Absolute Scaling (x / max|x|) preserves zeros exactly and is specifically noted for sparse data. Min-Max and mean normalization shift values by min/mean, which destroys zero-sparsity; StandardScaler also shifts by the mean.

2. Why do tree-based models like Random Forest and XGBoost not require feature scaling?

Explanation: Per the notes: "Tree models split data based on conditions, not distance." A split like age < 30 is invariant to the scale of the feature, so scaling changes nothing about the resulting splits.

3. Your income column has a handful of extreme millionaire outliers that you cannot remove because they carry real signal. Which scaler is designed for exactly this case?

Explanation: Robust Scaling uses median and IQR instead of mean/std/min/max, so it is not pulled around by extreme values — the notes list its "when to use" as exactly "data contains many outliers, outliers are important and cannot be removed."

4. You call scaler.fit_transform(X_test) instead of scaler.transform(X_test) on your test set. What specifically goes wrong?

Explanation: Per the deep-dive: "Do not fit again on test — use mean/std from train to scale test data. Prevents data leakage (ensures consistency)." Fitting on test recomputes statistics from data the model should never see during preprocessing setup, and train/test end up scaled on different bases.

5. A column has values [40, 400, 4000]. Using Decimal Scaling Normalization, what is the largest value's transformed result?

Explanation: Largest absolute value is 4000, which has 4 digits, so j = 4 and x' = x / 10^4 = x / 10000. For x = 4000: 4000/10000 = 0.4. (Compare to the source example: [12, 100, 500] with j=3, 500 → 0.5.)
