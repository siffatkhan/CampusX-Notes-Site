Binning and Binarization

Binning converts numerical values into categories. It is also called discretization.

Why Convert Numbers into Categories

Numbers are precise. Categories add structure. You bin to:

  • Reduce noise
  • Handle outliers
  • Improve model stability
  • Make patterns easier to learn
  • Improve interpretability
Example — Downloads: 23 → Low, 3,000 → Medium, 3,000,000 → High. Instead of raw values, you use categories.

Why Binning Helps with Outliers

Example — Salaries: 20k, 25k, 30k, 1,000,000. The last value skews the scale. Binning groups it into "High income" and reduces impact.

Types of Binning

1. Unsupervised Binning (no target variable involved)

a) Equal Width Binning (Uniform) — divide range into equal-sized intervals.

Example: Values: 0 to 100, Bins: 5, Bin width = 20.

  • 0–20
  • 21–40
  • 41–60
  • 61–80
  • 81–100
b) Equal Frequency Binning (Quantile) — each bin has the same number of samples.

Example: Scores: [10, 20, 30, 40, 50, 60, 70, 80], Bins: 4. Each bin has 2 values:

  • [10, 20]
  • [30, 40]
  • [50, 60]
  • [70, 80]
c) K-Means Binning — uses clustering to group similar values; centers define bins.

Example: Ages: [18, 19, 20, 35, 36, 37, 60, 61, 62], K=3 clusters:

  • Young: 18–20
  • Middle: 35–37
  • Senior: 60–62

2. Supervised Binning (uses target variable)

a) Decision Tree Binning — tree finds splits that best separate target classes; each leaf becomes a bin.

Example: Loan amount predicts default. Tree splits:

  • ≤ 50k → Low risk
  • 50k–200k → Medium risk
  • > 200k → High risk

3. Custom Binning

You define bins using domain knowledge.

Example — Age groups:

  • 0–12 → Child
  • 13–19 → Teen
  • 20–35 → Young adult
  • 36–60 → Adult
  • 60+ → Senior
Encoding Discretized Variables — after binning, you encode categories. Common encodings: Ordinal encoding (Low=0, Medium=1, High=2), One-hot encoding (Low=[1,0,0], Medium=[0,1,0], High=[0,0,1]).

Example concept: convert income into 3 bins using quantile strategy and ordinal encoding.

Binarization

What is binarization: convert values into 0 or 1 based on a threshold.

Why use it: for presence or absence, for yes or no decisions, for rule-based features.

$$ y = \begin{cases} 1 & x \geq \text{threshold} \\ 0 & x < \text{threshold} \end{cases} $$

Example: Score ≥ 50 → 1, Score < 50 → 0.

Sklearn: use the Binarizer class. You set a threshold. Values above threshold → 1. Values below or equal → 0.

5 questions on Day 32. Pick an answer for each, then check.

1. Scores [5, 10, 15, 20, 85, 90, 95, 100] are split into 4 bins using Equal Frequency (Quantile) binning. How many values land in each bin?

Explanation: "Equal frequency binning (Quantile) — each bin has same number of samples." Per the source example with 8 scores and 4 bins, each bin gets 2 values, regardless of how the raw value ranges compare (unlike equal-width binning, which keeps interval width equal instead).

2. A bank wants bins for "loan amount" that are chosen specifically to best separate defaulters from non-defaulters using the default label. Which binning type is this?

Explanation: Decision tree binning is the supervised technique that "uses target variable" — "Tree finds splits that best separate target classes. Each leaf becomes a bin," exactly matching the loan-default example given in the notes (≤50k → Low risk, 50k–200k → Medium, >200k → High).

3. Why does binning a salary column like [20k, 25k, 30k, 1,000,000] into income categories reduce the impact of the extreme 1,000,000 value?

Explanation: Per the notes: "The last value skews the scale. Binning groups it into 'High income' and reduces impact." Binning trades raw magnitude for a category label, so the extreme numeric value no longer dominates distance- or scale-based calculations.

4. You configure KBinsDiscretizer(n_bins=3, strategy="kmeans", encode="onehot"). What does the final output look like for each row?

Explanation: strategy="kmeans" uses clustering to define bins ("uses clustering to group similar values. Centers define bins"), and encode="onehot" produces one-hot columns (like "One-hot encoding: Low=[1,0,0]..."), not a single ordinal integer.

5. Using sklearn's Binarizer with threshold=50 on a score column, a row has score exactly equal to 50. What does it become?

Explanation: Per the sklearn Binarizer rule stated: "Values above threshold → 1. Values below or equal → 0." A value exactly equal to the threshold (50) falls in the "below or equal" case, so it becomes 0 — note this is stricter than the earlier general example "Score ≥ 50 → 1" which used ≥, so pay attention to which boundary rule is in force.
