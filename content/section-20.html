20. Polynomial Regression

Fitting curves with a linear model · feature transformation · when it breaks down

Day 61

Polynomial Linear Regression

1. What Problem It Solves

Linear regression fits a straight line. Some data is curved — a straight line fails to follow it. Polynomial regression fixes this by adding powers of the existing features.

Example. You try to predict price from size. The relationship curves upward. A straight line misses the pattern; a polynomial curve fits it.

2. Why It's Still Called "Linear" Regression

The trick: you create new features like x², x³, etc., but the relationship between the coefficients (the slopes) and y stays linear.

  • The model stays linear in its coefficients — no coefficient multiplies another coefficient
  • So optimization (least squares / gradient descent) stays exactly as simple as ordinary linear regression
  • Form stays: \( y = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \dots \)
$$ y = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \cdots $$

3. Underfitting vs Overfitting

RegimeCauseSymptom
UnderfittingLow degree, model too simpleMisses patterns, high bias
OverfittingHigh degree, model too complexTouches almost every point, learns noise, high variance

Goal: find the degree that balances both.

4–5. Feature Transformation (Two Inputs, Degree 2)

Say you have 2 input columns and choose degree = 2. Inputs: \(x_1, x_2\). We create polynomial features up to degree 2.

Original features

\(x_1, x_2\)

After polynomial expansion (degree 2)

\(1,\ x_1,\ x_2,\ x_1^2,\ x_2^2,\ x_1 x_2\)

Total features = 6

6. Final Model Equation

$$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_1^2 + \beta_4 x_2^2 + \beta_5 x_1 x_2 $$
  • \(x_1^2, x_2^2\) → capture curvature
  • \(x_1 x_2\) → captures interaction between features
Example. If study hours and sleep both increase, performance might rise differently than if either increased alone — that's interaction.

7. How Many Features Are Created

$$ \text{Number of features} = \frac{(n+d)!}{n! \, d!} $$

Where \(n\) = number of original features, \(d\) = degree. Here \(n=2, d=2 \Rightarrow 6\) features.

8. Small Numeric Example

Input: \(x_1 = 2,\ x_2 = 3\)
Transformed: \(1,\ 2,\ 3,\ 4\ (2^2),\ 9\ (3^2),\ 6\ (2 \times 3)\)
The model now uses these 6 values to predict y.

9. Code Example — scikit-learn

import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

# sample data (2 features)
X = np.array([
    [1, 2],
    [2, 3],
    [3, 4],
    [4, 5]
])

y = np.array([5, 9, 15, 23])

# create polynomial features (degree 2)
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)

print("Transformed Features:")
print(X_poly)

# train model
model = LinearRegression()
model.fit(X_poly, y)

# prediction
new = np.array([[5, 6]])
new_poly = poly.transform(new)

prediction = model.predict(new_poly)
print("Prediction:", prediction)

10. Key Intuition to Remember

  • You are not changing the model
  • You are changing the input space
  • You make the data linearly separable in higher dimensions
Simple view: original space → curved pattern. New (expanded) space → becomes linear.

11–12. Common Mistakes & When to Use

Common Mistakes

  • Using high degree blindly
  • Not scaling features before polynomial expansion
  • Ignoring interaction term importance
  • Not validating model on unseen data

Use vs Avoid

Use when: data shows a curve pattern, a simple linear model fails, feature interaction matters.

Avoid when: too many features and risk of overfitting is high.

5 questions on Day 61. Pick an answer for each, then check.

1. Why is polynomial regression still classified as "linear" regression even though it fits curves?

Explanation: Reusing sklearn's LinearRegression class (option D) is a consequence, not the reason. The real reason is structural: no coefficient multiplies another coefficient — the equation is linear in β₀, β₁, β₂… even though it's nonlinear in x. That's what keeps optimization as simple as ordinary least squares.

2. You have n = 3 original features and choose degree d = 2 for PolynomialFeatures. Using the formula (n+d)!/(n!·d!), how many total features result?

Explanation: (n+d)!/(n!·d!) = (3+2)!/(3!·2!) = 120/(6·2) = 10. (The n=2, d=2 example in the notes gives 6 — don't just re-apply that number to a different n.)

3. A degree-15 polynomial is fit to 20 noisy data points and achieves near-zero training error but performs terribly on new data. What is happening, in the notes' own vocabulary?

Explanation: High degree relative to the amount of data is the textbook overfitting setup: the model "touches almost every point," learns noise instead of signal, and has high variance — great training fit, poor generalization.

4. In the degree-2, 2-feature expansion \(1, x_1, x_2, x_1^2, x_2^2, x_1x_2\), which single term is specifically responsible for modeling how the two original features jointly affect y (beyond their individual effects)?

Explanation: \(x_1^2\) and \(x_2^2\) capture curvature in each feature individually. \(x_1x_2\) is the interaction term — it captures cases like "study hours and sleep both increasing changes performance differently than either alone."

5. Per the notes' "key intuition," what is actually happening when you apply PolynomialFeatures before fitting a LinearRegression?

Explanation: The notes are explicit: "You are not changing the model. You are changing the input space." The curved pattern in original space becomes fit-able by a linear function once you add the extra polynomial dimensions.
