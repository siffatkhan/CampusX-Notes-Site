4. Forward Propagation

Computing a Network's Output Layer by Layer · A Complete Worked Numeric Example

Day 10

What Forward Propagation Is

Forward propagation is the process of pushing an input through a neural network, layer by layer, to compute the network's final output (its prediction). It is called "forward" because information travels in one direction only — from the input layer, through each hidden layer in turn, to the output layer — with no loops or backward flow at this stage. Every layer performs exactly the same two-step operation from the previous chapter's "one equation to remember": first compute a weighted sum plus bias (\(z = Wx + b\)), then apply an activation function (\(a = f(z)\)) to get that layer's output, which becomes the input to the next layer.

Doing this by hand one neuron at a time works for a tiny network, but real networks have layers with dozens, hundreds, or thousands of neurons — so in practice, the computation for an entire layer is done in one shot using matrix multiplication: all the weights feeding into a layer are packed into a single weight matrix, all the neurons' biases into a single bias vector, and one matrix-vector multiplication computes every neuron's pre-activation value \(z\) in that layer simultaneously. The general layer-wise formula is:

$$ Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}, \qquad A^{[l]} = f\!\left(Z^{[l]}\right) $$

where \(A^{[l-1]}\) is the vector of activations coming out of the previous layer (with \(A^{[0]} = X\), the raw input, for the very first layer), \(W^{[l]}\) is the matrix of all weights feeding into layer \(l\) (shape: number of neurons in layer \(l\) × number of neurons in layer \(l-1\)), \(b^{[l]}\) is the bias vector for layer \(l\), and \(A^{[l]}\) is the vector of outputs from layer \(l\), which becomes the input to layer \(l+1\). Repeating this one formula, layer after layer, all the way to the output layer, is forward propagation.

Worked Example: 2 Inputs → 2-Neuron Hidden Layer → 1 Output Neuron

Take a tiny network: two input features \(x_1, x_2\), a hidden layer with two neurons \(h_1, h_2\), and a single output neuron \(o_1\) (as in a binary classifier). We'll use the sigmoid activation function, \(\sigma(z) = \frac{1}{1+e^{-z}}\), at every neuron.

Setup — inputs, weights, biases

Input vector: \(x_1 = 1.0\), \(x_2 = 0.5\).

Layer 1 (input → hidden) weights, using \(w_{ij}^{[1]}\) notation (\(i\)=input neuron, \(j\)=hidden neuron):

  • \(w_{11}^{[1]} = 0.3\) (x₁ → h₁), \(w_{21}^{[1]} = 0.6\) (x₂ → h₁), bias \(b_1^{[1]} = 0.1\)
  • \(w_{12}^{[1]} = 0.8\) (x₁ → h₂), \(w_{22}^{[1]} = -0.5\) (x₂ → h₂), bias \(b_2^{[1]} = -0.2\)

Layer 2 (hidden → output) weights:

  • \(w_1^{[2]} = 0.5\) (h₁ → o₁), \(w_2^{[2]} = -0.9\) (h₂ → o₁), bias \(b^{[2]} = 0.2\)

Step 1 — Layer 1 in matrix form

Pack the layer-1 weights into a 2×2 matrix (rows = hidden neurons, columns = input neurons) and the input into a column vector:

$$ W^{[1]} = \begin{bmatrix} 0.3 & 0.6 \\ 0.8 & -0.5 \end{bmatrix}, \quad X = \begin{bmatrix} 1.0 \\ 0.5 \end{bmatrix}, \quad b^{[1]} = \begin{bmatrix} 0.1 \\ -0.2 \end{bmatrix} $$

Compute \(Z^{[1]} = W^{[1]}X + b^{[1]}\):

$$ Z^{[1]} = \begin{bmatrix} 0.3(1.0) + 0.6(0.5) \\ 0.8(1.0) + (-0.5)(0.5) \end{bmatrix} + \begin{bmatrix} 0.1 \\ -0.2 \end{bmatrix} = \begin{bmatrix} 0.6 \\ 0.55 \end{bmatrix} + \begin{bmatrix} 0.1 \\ -0.2 \end{bmatrix} = \begin{bmatrix} 0.7 \\ 0.35 \end{bmatrix} $$

So \(z_{h_1} = 0.7\) and \(z_{h_2} = 0.35\). Written the scalar way, exactly as in the "one equation to remember": \(z_{h_1} = w_{11}^{[1]}x_1 + w_{21}^{[1]}x_2 + b_1^{[1]} = 0.3(1.0)+0.6(0.5)+0.1 = 0.7\), and \(z_{h_2} = w_{12}^{[1]}x_1 + w_{22}^{[1]}x_2 + b_2^{[1]} = 0.8(1.0)+(-0.5)(0.5)+(-0.2) = 0.35\).

Step 2 — Apply the activation function

Apply sigmoid to each entry of \(Z^{[1]}\) to get the hidden layer's actual output \(A^{[1]}\):

$$ a_{h_1} = \sigma(0.7) = \frac{1}{1+e^{-0.7}} \approx 0.6682, \qquad a_{h_2} = \sigma(0.35) = \frac{1}{1+e^{-0.35}} \approx 0.5867 $$

So \(A^{[1]} = \begin{bmatrix} 0.6682 \\ 0.5867 \end{bmatrix}\) — these two numbers are what the hidden layer passes forward; the raw inputs \(x_1, x_2\) are no longer used directly beyond this point.

Step 3 — Layer 2 (output layer) in matrix form

$$ W^{[2]} = \begin{bmatrix} 0.5 & -0.9 \end{bmatrix}, \quad A^{[1]} = \begin{bmatrix} 0.6682 \\ 0.5867 \end{bmatrix}, \quad b^{[2]} = 0.2 $$

Compute \(Z^{[2]} = W^{[2]}A^{[1]} + b^{[2]}\):

$$ Z^{[2]} = 0.5(0.6682) + (-0.9)(0.5867) + 0.2 = 0.3341 - 0.5280 + 0.2 = 0.0061 $$

Step 4 — Final activation → prediction

$$ \hat{y} = \sigma(0.0061) = \frac{1}{1+e^{-0.0061}} \approx 0.5015 $$

The network's final prediction is \(\hat{y} \approx 0.5015\). If this were a binary classifier trained to output "probability of class 1," this value is right at the decision boundary (0.5) — with these particular (untrained, illustrative) weights, the network is essentially undecided between the two classes. This is expected: nothing here has been trained yet. In practice, this \(\hat{y}\) would now be compared against the true label using a loss function (see the next chapter), and backpropagation would use that error to adjust every weight — \(w_{11}^{[1]}\) through \(w_2^{[2]}\) and both biases — so that future forward passes produce more accurate predictions.

The pattern to take away

Forward propagation, in full, is: multiply by weight matrix → add bias vector → apply activation, repeated once per layer, using the previous layer's activation output as the next layer's input. A network with 10 hidden layers just repeats this same pair of matrix operations 10 more times before reaching the output — no new concept is introduced by depth, only more repetitions of this one two-step rule.

Test Your Understanding

Hard

5 questions on forward propagation. Pick an answer for each, then check.

1. In the worked example, what is Z^[1] (the pre-activation values of the hidden layer) computed from X = [1.0, 0.5]?

Explanation: W^[1]X gives [0.6, 0.55]; adding the bias vector [0.1, -0.2] gives Z^[1] = [0.7, 0.35]. Option A is the result before adding bias.

2. What does A^[1] represent in the layer-wise formula Z^[l] = W^[l]A^[l-1] + b^[l]?

Explanation: A^[l] = f(Z^[l]) is the activation output of layer l, which then serves as the input (A^[l-1] from the next layer's perspective) for the following layer.

3. Why is matrix multiplication used instead of computing each neuron's z one at a time in code?

Explanation: Packing weights into a matrix lets one matrix-vector multiply compute the pre-activation values for an entire layer at once, instead of looping neuron by neuron — critical for layers with many neurons.

4. In the worked example, what is used as the input to Layer 2 (the output neuron)?

Explanation: Every layer's input is the previous layer's activated output, not its raw pre-activation z-values and not the original input (except for the very first layer).

5. What does forward propagation NOT do?

Explanation: Forward propagation only computes the prediction; adjusting weights based on error is the job of backpropagation, which happens afterward, using a loss function to compare ŷ against the true label.
