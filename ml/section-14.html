14. Missing Values

Removing Values · Numerical & Categorical Imputing · Random Sample / Missing Indicator · KNN Imputer · Iterative Imputer (MICE)

Day 35

Handling Missing Value — Removing Values

There are two broad families of approaches to missing data: Removing (covered today) and Imputing (filling in). Imputing splits further into univariate (fill using only that column — mean/median, random, end-of-distribution, via SimpleImputer) and multivariate (use other columns too — KNN imputer, iterative imputer).

Complete Case Analysis (CCA)

You remove rows where any column has missing values.

Example: 1000 rows, 50 rows have missing Age → you delete those 50 rows → you train on the remaining 950 rows.

Assumption

MCAR — Missing Completely At Random. Missing values are random, not linked to any feature or target.

When to use CCA
  • Missing data less than 5 percent
  • Data is MCAR
  • Dataset is large
  • Removing rows does not reduce statistical power
Problems
  • Lose data
  • If not MCAR, you introduce bias
  • Mean only uses rows where all values exist

Rule of thumb

Numerical data: less than 5 percent missing → CCA, mean, or median. Categorical data: replace with mode.

Day 36

Handling Numerical Missing Value (Imputing)

Univariate imputing means you use only that column to fill its own missing values. There are 4 techniques.

1. Mean Imputation

Use when data is normally distributed.

Effect: distribution becomes tighter; variance decreases; weakens relationship with other features; may introduce artificial central clustering.

Example: Age mean = 30 → all missing replaced with 30. Check variance before and after — variance shrinks after mean imputation.

2. Median Imputation

Use when data is skewed. More robust to outliers.

Example: Income data is right skewed → use median instead of mean.

3. Arbitrary Value Imputation

Replace missing with a fixed value. Used mostly for categorical or special flagging.

Example: Age missing → fill with 999.

4. End of Distribution Imputation

Used when missing may indicate extreme values. You push missing values to the extreme range.

  • If normal distribution: replace with mean + 3 × std, or mean − 3 × std
  • If skewed distribution: use the IQR rule — IQR = Q3 − Q1; upper bound = Q3 + 1.5 × IQR; lower bound = Q1 − 1.5 × IQR

Use when: missing values may represent abnormal cases, and you want the model to detect missing as extreme behavior.

Day 37

Handling Categorical Missing Value

Two techniques.

1. Most Frequent Replacement

Replace missing with the mode.

Example: City column — most common value is Lahore → fill missing with Lahore.

Use when: missing is random and a small percentage is missing.

2. New Category Method

Create a new label.

Example: Gender → Male, Female, Missing.

Use when: missing has meaning, MNAR is possible, or the missing percentage is high. Often improves tree models.

Day 38

Handling Missing Value — Random Sample / Missing Indicator

Random Sample Imputation

You randomly pick a value from existing non-missing values. Works for both numerical and categorical data.

Example: Age values 20, 25, 30, 40 → a missing row randomly gets one of these.

Advantages
  • Preserves distribution
  • Preserves variance
  • Good for linear models
Disadvantages
  • Need stored distribution during deployment
  • More memory usage

Missing Indicator

You add a new binary column.

Example: Age_missing — 1 if Age was missing, 0 if not.

Useful when: missing itself carries information — often improves accuracy. SimpleImputer(add_indicator=True) adds this automatically.

Automatic Selection of Parameter

Grid Search CV for Best Imputation — you treat imputation strategy as a hyperparameter.

Example: test Mean, Median, Most frequent, KNN — the model chooses the strategy with the best cross-validation score.

Day 39

Handling Missing Value (Multivariate) — KNN Imputer

Univariate imputing ignores other columns. Multivariate imputing uses other features to estimate missing values. Two techniques exist: KNN Imputer (today) and Iterative Imputer (Day 40).

KNN Imputer

Uses K Nearest Neighbors. Example dataset:

AgeSalary
2550k
3060k
3580k
NaN55k

To fill missing Age:

  1. Compute distance between the missing row and other rows using Salary
  2. Find K nearest rows based on Euclidean distance
  3. Take average Age of the nearest neighbors
Worked example, K = 2: closest Salary rows are 50k and 60k → their Ages are 25 and 30 → imputed Age = 27.5.
Advantages
  • More accurate
  • Uses structure in data
Disadvantages
  • Slow, heavy computation
  • Needs full dataset at prediction time — memory expensive
Day 40

Handling Missing Value (Multivariate) — Iterative Imputer (MICE)

MICE means Multivariate Imputation by Chained Equations. Idea: each column with missing values is predicted using other columns as predictors.

Missing Types

TypeMeaningExample
MCARMissing completely at random. No pattern.—
MARMissing depends on other observed variables.Salary missing depends on Education level
MNARMissing depends on an unobserved variable or the value itself.High earners hide their salary

How Iterative Imputer Works

Example columns: Age, Salary, Experience.

  1. Initialize missing values with a simple method like mean
  2. Pick one column with missing values — suppose Age
  3. Use other columns, Salary and Experience, to train a regression model predicting Age
  4. Predict the missing Age values
  5. Move to the next column with missing values, repeat the same process
  6. Repeat the full cycle multiple times until values stabilize

This repeated cycle of predicting each column from the others is what creates "chained equations."

Advantages
  • More accurate
  • Uses relationships between features
Disadvantages
  • Slow
  • High memory usage
  • Complex
  • Risk of overfitting
EXTRA — How to choose the best imputation method
Step 1: Check missing percentage
  • Less than 5 percent → CCA or simple imputation
  • 5 to 20 percent → median, mode, or random sample
  • More than 30 percent → consider dropping the feature
Step 2: Check missing mechanism
  • MCAR → CCA or simple works
  • MAR → multivariate works better
  • MNAR → add missing indicator or new category
Step 3: Check distribution
  • Normal → mean
  • Skewed → median
  • Extreme meaning → end of distribution
Step 4: Check model type
  • Linear models — sensitive to variance, prefer random sample or multivariate
  • Tree models — handle missing better, new category works well
Step 5: Check computational limits
  • Low memory → mean or median
  • High memory allowed → KNN or Iterative
Step 6: Validate with cross validation

Use GridSearchCV, compare model score. Always measure accuracy, variance change, and feature correlation change.

Core Principle: never choose a method blindly. Understand why the data is missing, how much is missing, what model you are using, and what resources you have.
Model type matters: Linear/Logistic Regression are sensitive to variance shrinkage — prefer random sample or multivariate imputation. Tree models like Random Forest handle imputation noise better — median works fine.

Test Your Understanding

Hard

5 questions on Day 35–40. Pick an answer for each, then check.

1. A dataset has 2 percent missing values in a numerical column, and you have confirmed the missingness is MCAR. Which approach is most appropriate?

Explanation: CCA's stated conditions are: missing data less than 5 percent, data is MCAR, and dataset is large. Both conditions here are satisfied, so CCA is appropriate — it avoids the bias risk that would appear if the mechanism weren't MCAR.

2. After applying mean imputation to a numerical column, you compare variance before and after. What should you observe, and why does this matter?

Explanation: Mean imputation replaces every missing entry with the same single mean value, creating artificial central clustering. This tightens the distribution and shrinks variance, which also weakens the column's relationship with other features — a documented side effect in the notes.

3. Given Age=25→Salary=50k, Age=30→Salary=60k, Age=35→Salary=80k, and a row with Salary=55k and missing Age, what does KNN Imputer with K=2 predict for Age?

Explanation: With K=2, the two Salary values closest to 55k are 50k and 60k (not 80k). Their corresponding Ages are 25 and 30, averaging to 27.5 — exactly the worked example in the notes.

4. In an Iterative Imputer (MICE) run with columns Age, Salary, and Experience, how is a missing Age value predicted?

Explanation: MICE initializes with a simple method, then for each column with missing values, trains a regression model using the other columns as predictors, predicts the missing values, and repeats the full cycle until values stabilize — this is what "chained equations" means. Option B describes KNN Imputer, a different technique.

5. A categorical column is 40 percent missing, and you suspect the missingness itself is meaningful (MNAR) — e.g., people with a certain trait chose not to answer. Which is the best-fit technique per the "how to choose" framework?

Explanation: New Category Method is explicitly recommended when missing has meaning, MNAR is possible, and the missing percentage is high — all three conditions apply here. Mode replacement is meant for random, small-percentage missingness, which is the opposite situation.
