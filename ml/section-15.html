15. Outliers

Detecting & Treating Outliers · Z-Score Method · IQR Method · Winsorization

Day 41

Handling Outliers

Outliers are extreme values that lie far from most observations.

Example: an Age column mostly between 18 and 70 — one record shows age = 300.

In data cleaning, you often remove outliers. In anomaly detection or fraud detection, outliers are the target, so you keep them.

Why Outliers Matter in ML

Highly Affected by Outliers Why
Linear RegressionOne extreme value increases error heavily; the line shifts toward the outlier
Logistic RegressionUses gradient descent; extreme values affect coefficient updates
AdaBoostFocuses on misclassified points; outliers get high weight
Deep LearningUses gradient descent; large values create large gradients, training becomes unstable

Reason: these models rely on distance or error magnitude. Outliers increase error significantly.

Less Affected by Outliers Why
Decision TreeSplits based on thresholds; one extreme value does not shift all splits
Random ForestEnsemble of trees; robust to noise
Gradient BoostingTree-based boosting; less sensitive than linear models
XGBoostRegularized tree boosting; handles outliers better

Reason: tree models split data using rules, not distance from the mean.

How to Detect Outliers

A. Normal Distribution — Z-score rule

$$ Z = \frac{x - \text{mean}}{\text{standard deviation}} $$

If Z > +3 or Z < −3, the value is considered an outlier.

B. Skewed Distribution — IQR method

IQR = Q3 − Q1. Lower bound = Q1 − 1.5 × IQR. Upper bound = Q3 + 1.5 × IQR. If value < lower bound or value > upper bound → it is an outlier.

C. Any Distribution — Percentile method

Lower threshold = 2.5th percentile, upper threshold = 97.5th percentile. Values outside these limits are treated as outliers. You choose the percentile based on tolerance.

How to Treat Outliers

A. Trimming

Remove rows containing outliers.

Use when: outliers are errors, data size is large, extreme values are unrealistic. Risk: you lose information.

B. Capping / Winsorization

Replace extreme values with boundary values. Example: if upper limit = 100, any value > 100 becomes 100.

Use when: outliers are real but too extreme, you want to reduce influence — good for linear models.

C. Treat outliers as missing

Mark them as NaN, then impute using mean, median, or a model.

Use when: the value is likely a measurement error.

D. Discretization

Convert continuous variable into bins. Example: Income → 0–20k, 20k–50k, 50k+.

Effect: reduces impact of extreme values, makes model less sensitive. Common in tree-based or logistic models.

Practical Workflow

  1. Understand business objective
  2. Visualize distribution through histogram or boxplot
  3. Detect using Z-score for normal data and IQR for skewed data
  4. Decide treatment based on model type, domain knowledge, data size

Techniques for outlier detection and removal: Z-score treatment, IQR based filtering, Percentile, Winsorization.

Day 42

Handling Outliers — Z-Score Method

Z-score measures how many standard deviations a value is from the mean.

$$ Z = \frac{x - \text{mean}}{\text{standard deviation}} $$

Empirical Rule for Normal Distribution

  • 68 percent of values lie within ±1 standard deviation
  • 95 percent of values lie within ±2 standard deviations
  • 99.7 percent of values lie within ±3 standard deviations

Outlier rule: if Z > 3 or Z < −3 → treat as outlier.

Important: the Z-score method works properly only when data is approximately normal.

Finding Outlier Boundaries

Upper limit = mean + 3 × standard deviation. Lower limit = mean − 3 × standard deviation.

Example for column cgpa:

upper_limit = df['cgpa'].mean() + 3 * df['cgpa'].std()
lower_limit = df['cgpa'].mean() - 3 * df['cgpa'].std()

# Detecting outliers using boundaries
df[(df['cgpa'] > upper_limit) | (df['cgpa'] < lower_limit)]

# Calculating a Z-score column
df['cgpa_zscore'] = (df['cgpa'] - df['cgpa'].mean()) / df['cgpa'].std()

# Keeping only non-outlier rows (Z-score between -3 and 3)
df[(df['cgpa_zscore'] < 3) & (df['cgpa_zscore'] > -3)]

Trimming

Remove rows where outliers exist.

Use when: outliers are data errors, dataset size is large. Risk: loss of information.

Capping

Instead of removing rows, replace extreme values with boundary values.

If value > upper_limit → replace with upper_limit. If value < lower_limit → replace with lower_limit. Else → keep original value. Implemented with np.where: assign upper limit if above, lower limit if below, otherwise keep original value.

Day 43

Handling Outliers — IQR Method

When to use IQR: use it for skewed data. Do not use Z-score if the distribution is not normal.

# Visualize using boxplot
sns.boxplot(x = df['cgpa'])

# Checking skewness
df['cgpa'].skew()

Interpreting skew

  • Skew ≈ 0 → symmetric distribution
  • Skew > 0 → right skewed, long right tail
  • Skew < 0 → left skewed, long left tail

A larger absolute value means stronger skewness.

Percentiles: 25th percentile (Q1) — 25 percent of values lie below this. 75th percentile (Q3) — 75 percent of values lie below this.

$$ IQR = Q_3 - Q_1 $$

IQR measures the spread of the middle 50 percent of the data.

$$ \text{Lower limit} = Q_1 - 1.5 \times IQR \qquad \text{Upper limit} = Q_3 + 1.5 \times IQR $$

Any value < lower limit → outlier. Any value > upper limit → outlier.

# Finding Q1 and Q3
Q1 = df['cgpa'].quantile(0.25)
Q3 = df['cgpa'].quantile(0.75)
IQR = Q3 - Q1

lower_limit = Q1 - 1.5 * IQR
upper_limit = Q3 + 1.5 * IQR

# Detecting outliers
df[(df['cgpa'] < lower_limit) | (df['cgpa'] > upper_limit)]
Day 44

Handling Outliers — Winsorization

Winsorization means capping extreme values instead of removing them. You replace outliers with boundary percentile values. No rows are deleted.

Common practice

1st percentile as lower limit, 99th percentile as upper limit. Sometimes 5th and 95th percentiles are used if data is highly noisy.

How it Works

  1. Find percentile limits — lower limit = 1st percentile, upper limit = 99th percentile
  2. Replace values — if value < lower limit → set equal to lower limit; if value > upper limit → set equal to upper limit; else → keep original value
Why use Winsorization
  • Prevent data loss
  • Reduce effect of extreme values
  • Stabilize linear and gradient-based models
  • Useful for financial or income data
When to use
  • Outliers are real but extreme
  • Dataset is small
  • Using linear regression, logistic regression, or deep learning

Important difference

Trimming removes rows. Winsorization keeps rows, modifies values.

Explanation: Tree-based models (Decision Tree, Random Forest, Gradient Boosting, XGBoost) split data using threshold rules rather than distance or error magnitude, so one extreme value doesn't shift all splits — making them comparatively robust to outliers.

Explanation: The notes state Z-score "works properly only when data is approximately normal," and explicitly say "Use IQR method for skewed data. Do not use Z-score if distribution is not normal." A skew of 2.8 is strongly right-skewed, so IQR is the correct choice.

4. For a column, Q1 = 40 and Q3 = 70. Using the standard IQR rule, what is the upper bound for outlier detection?

Explanation: IQR = Q3 − Q1 = 70 − 40 = 30. Upper limit = Q3 + 1.5 × IQR = 70 + 1.5 × 30 = 70 + 45 = 115.

Explanation: Winsorization is recommended precisely for small, noisy datasets and linear/gradient-based models, since it caps extreme values at percentile boundaries (e.g. 1st/99th) without deleting rows — unlike trimming, which removes rows entirely.
